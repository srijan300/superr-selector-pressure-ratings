## What is in this package

- `submission/`: the report PDF, the rankings CSV and this guide.
- `analysis/`: the full pipeline. `analysis/README.md` explains how to run it.
- `dashboard/`: the source of the published dashboard page.

The data pack is not included. To rerun the pipeline, unzip the competition data pack into `dataPack/` at the project root, so the CSVs sit in `dataPack/Data Pack/`.

## Before submitting
