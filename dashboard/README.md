# Pressure ratings dashboard

Static page for SupeRR Selector Season 2, Round 1: which T20 batters and bowlers deliver when the match is on the line.

- `index.html`, `dashboardStyles.css` and the `*.js` modules are the page. No build step and no chart library; the charts are hand-drawn SVG.
- `dashboardData.js` is generated by the analysis pipeline and holds player-level summaries only. The ball-by-ball data pack is not in this repository.
- `methodologyReport.pdf` is the full methodology report.

To view locally, serve this folder over HTTP (ES modules do not load from `file://`):

    python -m http.server 8765
